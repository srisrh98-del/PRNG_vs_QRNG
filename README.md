# PRNG_vs_QRNG

This project presents a comparative analysis of classical pseudo-random number generators (PRNGs) and quantum random number generators (QRNGs) using Python and Qiskit.
It explores the statistical quality, entropy, and unpredictability of random bit sequences generated by both approaches.

# Objective


1. Generate random bit sequences using both PRNG and QRNG methods.
2. Quantitatively compare their randomness using multiple entropy metrics.
3. Visualize entropy distributions and randomness deviations using matplotlib plots.
4. Highlight practical implications for fields like cryptography, satellite communication, and secure key distribution.


# Results Summary

PRNG: High-speed but limited by algorithmic determinism and periodic patterns.
QRNG: Lower throughput but demonstrates true physical randomness from quantum measurement outcomes.
Visual analysis shows higher entropy stability and broader uniformity in QRNG data distributions.

# Applications

Quantum Key Distribution (QKD)
Secure Satellite Communications
Cryptographic Key Generation
Quantum Cryptography Protocols
